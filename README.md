# BuyBox Monitor

BuyBox Monitor is a local-rule-driven monitoring site for:

- Keepa daily uploads
- SKU / ASIN watch lists
- Mapping information
- KMASIN and competitor ASIN comparison
- Price, rank, and Buy Box change tracking

## Local development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
